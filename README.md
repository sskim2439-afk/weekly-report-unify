# 주간업무보고 양식 통일 도구

여러 부서의 주간업무보고 엑셀 파일을 넣으면 글머리 기호와 글꼴을 한 가지 양식으로 통일한 새 파일을 만들어 줍니다.

- 🗸 대표 활동 (네오현대 B) / `   - ` 하위 항목 (네오현대 L) / `      · ` 세부 항목 (네오현대 L)
- 🗸 묶음 사이 빈 줄 1줄, 사진·도형·대괄호 제목은 그대로 유지
- 결과 파일명: `부서명_주간업무보고_작업날짜.xlsx` (예: `SCM본부_주간업무보고_261023.xlsx`)

## 필요한 환경

- Windows PC + Microsoft Excel
- 네오현대 글꼴(네오현대 B, 네오현대 L) 설치
- 회사 문서보안 프로그램이 설치된 PC (보안이 걸린 파일도 Excel이 열 수 있어야 함)

## 사용 방법

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. `양식통일_시작.bat`을 더블클릭합니다. 검은 창이 뜨고 브라우저가 자동으로 열립니다.
3. 왼쪽 **양식 통일 전** 칸에 파일을 여러 개 끌어다 놓고 **양식 통일하기**를 누릅니다.
4. 오른쪽 **양식 통일 버전** 칸에서 이름을 확인·수정한 뒤 개별 또는 ZIP으로 내려받습니다.
5. 다 쓰면 **도구 종료** 버튼을 누르거나 검은 창을 닫습니다.

파일은 PC 밖으로 나가지 않습니다. 내 PC 안에서만 열리는 주소(localhost)로 동작하고, 변환은 내 PC의 Excel이 합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `양식통일_시작.bat` | 도구 실행 |
| `server.ps1` | 내 PC 안에서만 도는 작은 서버 (업로드·다운로드 처리) |
| `convert.ps1` | 양식 통일 규칙 (Excel로 변환) |
| `index.html` | 화면 |

## 문제가 생기면

- 실행이 바로 꺼지면: 회사 보안 정책이 PowerShell 실행을 막고 있을 수 있습니다. 검은 창의 문구를 담당자에게 알려 주세요.
- 부서명이 이상하게 나오면: 오른쪽 결과 칸에서 파일 이름을 직접 고친 뒤 받으면 됩니다.
